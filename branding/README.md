# Nexora OS Branding

This directory contains brand assets for the Nexora OS project — infrastructure for African commerce.

## Contents

- [`logo.md`](logo.md) — Primary logo mark and wordmark
- [`color-palette.md`](color-palette.md) — Light/dark color system with accessibility guidelines
- [`typography.md`](typography.md) — Inter + DM Sans scale and usage
- [`hero-block.md`](hero-block.md) — Landing page hero block with copy and honesty ledger

## Quick Start

To use these assets:

1. **Logo**: The wordmark "Nexora OS" in Inter typeface, Midnight color (`#1A1A2E`)
2. **Colors**: 
   - Light mode: Sand background (`#F5F0E8`), Midnight text (`#1A1A2E`), Azure accents (`#0066FF`)
   - Dark mode: Obsidian background (`#0D0D18`), Azure accents (`#0066FF`)
3. **Typography**: Body in Inter Regular (16px), Headings in DM Sans
4. **Messaging**: Tagline "Honest infrastructure for African commerce — built, not decked."

## Brand Voice Quick Reference

- **DO**: Be direct, outcome-focused, short sentences, plain language
- **DON'T**: Use AI vocabulary (delve, robust, comprehensive, nuanced), em dashes, hype phrases
- **Tagline**: "Honest infrastructure for African commerce — built, not decked."
